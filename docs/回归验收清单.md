## 4. 数据与自愈

- [ ] 手动刷新：状态行「更新 N 个」、最近取数时间刷新
- [ ] **刷新无响应要说出来**：制造签名页故障（如断网）后点刷新 → 20 秒内出现「刷新没拿到结果…」，不许永久「手动刷新中」
- [ ] **状态行自己在走**：冷启动后 10 秒内状态行必须显示真实状态（不许停在「监控服务未运行（正在拉起…）」这类开局文案不放）
- [ ] **连续第二轮回归**：第一轮 result 后 tick 回到 busy=false，60 秒内自然发生第二轮；冒烟脚本 6b 步（点刷新 → lastSuccess 必须前进）每版必跑
- [ ] **飞行模式测喊人**：断网后连败 → 第 3 败出「开播监控异常」通知（含原因），退避间隔递增
- [ ] **数据防线**：飞行模式下取数 = 失败路径（不走 `follower<=0` 破坏分支）；恢复网络后自动回绿
- [ ] **停摆哨兵**：断网超 30 分钟观察 4004 停摆通知（2 小时去重）
- [ ] 0 点快照：`dywatch-daily.json` 出现当日条目；漏采自动补（backfill）
- [ ] 刷新时若当日无快照：会顺手补一条（`handleResult` 里 `putDaily(backfill=true)`）
- [ ] 重启 App：无重复提醒（wasLive 识别同一场）
- [ ] 本地 JSON 损坏：留 `.bak` 且状态行提示（v1.2.4 起）

## 6. 更新机制（v1.2.6 起，真机四步）

- [ ] 发一个 versionCode 更大的 release，体检页「检查」→ 出现「安装 vX」行
- [ ] 「下载并安装」→ 系统安装器弹出 → 装完打开是新版本，本地曲线还在
- [ ] 反证：把 release 上 sha256 改错一位 → 应「校验和不匹配，已删除下载的包」
- [ ] 未授权「安装未知应用」时：显示「去授权」，点了能跳到系统页

## 7. 已知机型坑（分发说明与自测对照）

| 坑 | 症状 | 药方 |
|---|---|---|
| MIUI/HyperOS 后台弹出界面+锁屏显示未开 | 悬浮弹窗能出但点按钮没反应、锁屏页不弹 | 应用详情开 4 权限 |
| 通知渠道被 ROM 关到静音 | 服务绿但提醒全瞎 | 体检页红叉 → 渠道设置 |
| 电池优化杀服务 | 提醒延迟/停摆通知 | 体检页加白名单 |
| 老 WebView 加载 douyin.com 白屏 | 一直「取数还没成功过」 | 更新 Android System WebView |
| 闹钟权限没给（12+） | 0 点快照晚 ≤10 分钟 | 体检页黄三角 → 去开启 |
| 通知小图标改了不刷新 | 通知里还是旧图标 | HyperOS 按应用缓存；靠 setLargeIcon 绕过 |
| 换机器/删 debug keystore | 新包装不上（签名不符） | 只能卸载重装，本地曲线会丢 |
